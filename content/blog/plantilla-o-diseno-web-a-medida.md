Cuando cotizas una web, tarde o temprano aparece esta pregunta: ¿conviene una plantilla o un diseño a medida? La respuesta corta es que depende menos del diseño que de lo que pasa después del lanzamiento: quién mantiene la web, cuánto cuesta cada cambio y qué tan fácil es crecer.

Esta guía te ayuda a decidir con criterios concretos.

## Qué es cada opción

**Una web con plantilla** parte de un diseño ya hecho, normalmente en una plataforma como WordPress, Wix o Shopify. Se cambian textos, imágenes y colores, y se agregan funciones con complementos (plugins).

**Una web a medida** se diseña y construye para tu empresa: la estructura, el diseño y el código responden a lo que necesitas comunicar. No depende de un tema comprado ni de complementos de terceros para funcionar.

Ninguna es mejor por definición. Son herramientas para situaciones distintas.

## La comparación que importa

| Criterio | Plantilla | A medida |
|---|---|---|
| Costo inicial | Menor | Mayor |
| Tiempo de salida | Rápido, si el contenido está listo | Algo más, por el diseño propio |
| Diferenciación | Limitada: otras empresas usan la misma base | Alta: el diseño expresa tu marca |
| Mantenimiento | Actualizaciones frecuentes de plataforma, tema y plugins | Menos piezas que actualizar |
| Velocidad | Variable; cada plugin suma peso | Se optimiza desde el inicio |
| Seguridad | Depende de mantener todo actualizado | Menos superficie expuesta |
| Autonomía para editar | Alta, si la plataforma es amigable | Depende de si incluye un panel de edición |
| Crecimiento | Fácil mientras la plantilla lo permita | Se diseña pensando en lo que viene |

## Cuándo una plantilla es suficiente

- Estás validando un negocio y necesitas presencia rápido.
- Tu oferta es simple y tu marca todavía está en formación.
- Tienes a alguien que mantendrá la plataforma actualizada.
- La web no es un canal comercial clave, sino una tarjeta de presentación.

En estos casos, una buena plantilla bien configurada puede ser la decisión correcta.

## Cuándo conviene una web a medida

- La web es una pieza central de tu venta: de ahí salen consultas, reservas o pedidos.
- Tu marca necesita diferenciarse de competidores que se ven todos iguales.
- Necesitas integraciones (formularios conectados, reservas, pagos, paneles) que con plugins se vuelven frágiles.
- Ya tuviste una web con plantilla y el mantenimiento se volvió una fuente de problemas.

## El costo que no aparece en la cotización

La diferencia de precio inicial suele ser lo primero que se compara, pero no es lo único:

- **Licencias:** temas premium, plugins de pago y renovaciones anuales.
- **Mantenimiento:** actualizar la plataforma y los complementos, y resolver incompatibilidades cuando una actualización rompe algo.
- **Velocidad:** una web lenta cuesta visitas y consultas, y optimizar una plantilla cargada no siempre es posible.
- **Dependencia:** si nadie en tu equipo sabe administrarla, cada cambio pequeño pasa por un tercero.

Por eso conviene comparar el costo del primer año, no solo el del lanzamiento. Lo explicamos con detalle en [cuánto cuesta una página web en Perú](/blog/cuanto-cuesta-pagina-web-peru/).

## Preguntas para hacerle a tu proveedor

1. ¿Qué plataforma usarán y quién será el dueño de la cuenta, el dominio y el alojamiento?
2. ¿Cuántos complementos o servicios de terceros necesita la web para funcionar?
3. ¿Quién la mantendrá actualizada y cuánto cuesta ese servicio?
4. ¿Podré editar textos, imágenes y precios sin ayuda? ¿Desde el celular?
5. ¿Qué pasa si mañana quiero agregar una función nueva?
6. ¿Cómo se medirá si la web genera consultas?

Las respuestas suelen decir más que el precio.

## Un punto intermedio

Hay una tercera vía: una web con diseño propio que incluya un panel para que tu equipo edite el contenido, sin depender de una plataforma de plantillas ni de plugins.
